Consumer Access Assistant | Proposal2

Evidence first, then a verdict

1

Read-only tools

Collect facts from AD, Immuta, Snowflake and query history. 82 catalogued, 32 in the MVP.

2

Decision engine

Tested code, not the AI model, compares the access a user should have with what they actually have.

3

Chat assistant

Explains the verdict in plain language, shows the evidence and gives the one next step.

Four possible verdicts, each with a clear owner

Should have, and has

Session set-up issue. The user gets the exact fix.

Should have, has not

Platform fault. Escalated with the evidence.

Should not, has not

Working as designed. User is told what to request.

Should not, but has

Excess access. Flagged to governance.

The same tools also run on a schedule, to find sync faults before users report them.
